MUNICIPAL ANALYTICS PROJECT

Does cultural expenditure influence citizen satisfaction?

This project investigates whether higher municipal expenditure on cultural and leisure activities is associated with stronger citizen satisfaction outcomes across Flemish municipalities. Using data from the Vlaamse Gemeente-Stadsmonitor, interactive dashboards were developed to explore patterns, identify outliers and support evidence-based interpretation.

View Dataset Methodology
PROJECT DESIGN

Methodology

Dataset

Vlaamse Gemeente-Stadsmonitor

Variables

Cultural expenditure and citizen satisfaction indicators

Coverage

Flemish municipalities

Approach

Interactive visual analytics using Tableau

01

Regression Analysis

Investigating the relationship between cultural expenditure and municipal satisfaction.

Key Takeaway

The regression dashboard provides an overview of how expenditure levels relate to perceived cultural satisfaction. It allows identification of municipalities that perform above or below expectations relative to spending levels.

02

Municipality Comparison

Comparing municipalities and identifying regional patterns.

Key Takeaway

The municipality comparison dashboard supports exploratory analysis by highlighting differences between municipalities and enabling interactive comparison of local performance.

INSIGHTS

Key Findings

01

Positive relationship observed

Municipalities with higher cultural expenditure tend to report stronger satisfaction outcomes.

02

Outliers exist

Several municipalities perform better than expected despite moderate expenditure levels.

03

Context matters

Expenditure alone does not fully explain variation in satisfaction outcomes.

Limitations

This analysis is exploratory and focuses on observed relationships between expenditure and satisfaction. Correlation does not imply causation and additional demographic, economic and policy-related variables may influence citizen perceptions.

Academic Disclaimer

Developed as part of the KU Leuven Data Visualisation course using data from the Vlaamse Gemeente-Stadsmonitor.
